## Bounds and preservation

New database migrations 0008/0009 are additive and transactional. Downgrades that
would discard reviews/overlays refuse. No old report schema, canonical report
serialization, report selection, annotation history or stored file is rewritten.
Review JSON: 4 MiB; source read: 32 MiB (Ghidra keeps its stricter 2 MiB reader);
export JSON: 8 MiB; HTML: 16 MiB. No successful-looking export truncation.
Byte windows: 1–4,096 bytes; UI uses 256. The file digest/size is checked before
returning any bytes; at most the admitted 64 MiB file is read per request.
Source evidence and note bodies never become executable HTML or automatic URLs.

Privacy applies to the derivative bytes. Original strings, tool outputs,
pseudocode, filenames and overlay revisions remain in local application storage.
Function overlay exports contain the revision captured at pin time; later edits
require a refreshed snapshot. A valid note citation is not endorsement of its
claim. Reviewed state does not mean harmless.
